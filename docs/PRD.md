## 1. نظرة عامة

**تك زون** هو نظام متكامل لنقاط البيع (POS) وإدارة المبيعات والمخزون والعملاء والصيانة وشراء الأجهزة المستعملة، مصمم خصيصاً لمحلات الإلكترونيات في السوق المصري. يعمل النظام **offline بالكامل** بدون أي اتصال بالإنترنت، بواجهة عربية (RTL) تحاكي نظام تشغيل هجين يجمع بين تصميم Windows 11 و macOS — يشمل سطح مكتب متعدد النوافذ العائمة، شريط مهام، قائمة ابدأ، وDock سفلي.

يعمل النظام داخل نافذة `pywebview` واحدة بوضع `maximized`، ويدعم الوضع النهاري والليلي بتزامن كامل عبر سطح المكتب وجميع النوافذ الداخلية، ومهيأ للسوق المصري (عملة: ج.م / LE، ضريبة 14% قابلة للتفعيل أو الإيقاف).

## 3. المستخدمون المستهدفون

### 3.1 مدير المحل (Admin)
- يملك كافة الصلاحيات الـ 16 تلقائياً بدون استثناء.
- يدير إعدادات المتجر (الاسم، الشعار، الضريبة، طرق الدفع، قوالب الفواتير، طريقة تسجيل الدخول).
- يضيف ويعدل الموظفين ويخصص صلاحياتهم الفردية عبر صفحة إدارة الموظفين (`staff.html`).
- يراجع التقارير المالية والورديات والمخزون والمرتجعات.
- يتحكم في أوضاع تسجيل الدخول الثلاثة (`pin_only` / `select_user_pin` / `username_password`).

### 3.2 موظف الكاشير (Cashier)
- يعمل بصلاحيات محددة يحددها المدير من الـ 16 صلاحية المتاحة.
- يستخدم بشكل أساسي شاشة نقاط البيع (POS) لإجراء عمليات البيع السريعة.
- يفتح ويغلق الورديات مع إدخال جرد النقدية.
- يمكنه تعديل ملفه الشخصي (الاسم، الصورة، الرمز السري، صفحة البداية، مظهر سطح المكتب) عبر `profile.html`.
- لا يرى الأقسام المحظورة عليه في القوائم والشريط الجانبي.

## 6. المتطلبات غير الوظيفية

| # | المتطلب | التفاصيل |
|---|---|---|
| 1 | **العمل بدون إنترنت** | النظام يعمل offline بالكامل — كل الخطوط (23 ملف `.woff2`) والأيقونات محلية في `web/fonts/`، لا طلبات شبكة نهائياً |
| 2 | **نافذة واحدة** | يعمل داخل نافذة `pywebview` واحدة بوضع `maximized` (حد أدنى `360×500`)، النوافذ الداخلية تفتح كـ `iframe` عائمة داخل سطح المكتب |
| 3 | **واجهة عربية RTL** | كافة الصفحات والنصوص والقوائم بالعربية مع اتجاه RTL صحيح، بما في ذلك الفواتير والإيصالات المطبوعة |
| 4 | **السوق المصري** | العملة: جنيه مصري (ج.م / LE)، ضريبة القيمة المضافة 14% قابلة للتفعيل أو الإيقاف الكامل من الإعدادات |
| 5 | **نظام التشغيل** | Windows 10 / 11 مع WebView2 Runtime (مثبت تلقائياً في Windows 11) |
| 6 | **دقة الشاشة** | تصميم متجاوب يعمل من دقة `360×500` كحد أدنى، مُحسَّن لدقة `1360×860` وأعلى |
| 7 | **الوضع النهاري/الليلي** | دعم كامل للوضع الفاتح والداكن متزامن عبر سطح المكتب وكافة النوافذ الداخلية، مع حفظ تفضيل كل مستخدم |
| 8 | **الأمان** | تسجيل دخول بالرمز السري مع تشفير `pin_hash` + `pin_salt`، قفل بعد محاولات فاشلة، صلاحيات مخصصة لكل موظف تُفحص في الواجهة والخلفية |
| 9 | **التخزين** | قاعدة بيانات SQLite واحدة (`data/shop.db`)، المبالغ تُخزن كأعداد صحيحة بوحدات القرش (1 جنيه = 100 قرش) لتجنب أخطاء الكسور العشرية |
| 10 | **الأداء** | تحميل أي صفحة في أقل من ثانيتين، عرض 500+ منتج بسلاسة، بحث فوري بدون تأخير ملحوظ |
| 11 | **لا تبعيات خارجية إضافية** | ممنوع: React / Electron / Rust / .NET / bundler / مكتبات runtime جديدة — فقط Python 3.13 + sqlite3 + pywebview + Tailwind CSS مُجمَّع + vanilla JS |
